# A Parsimonious Predictor of Pre-training Dynamics

Source of the blog post at https://matheart.github.io/parsimonious-predictor/.
This repository holds the official version of the page. GitHub Pages serves the `main` branch as it is, with no build step, so a push to `main` is live after a minute or two.

The code and data that produce the results are in [interpretable-curve-prediction](https://github.com/Matheart/interpretable-curve-prediction).

## Files

```
index.html                      the post: styles, text and figure containers
figs.js, traj.js                draw the interactive figures (Plotly)
data/traj_data.js               numbers behind the data-driven figures
figures/teaser.svg, .png        teaser figure (the PNG is the link preview image)
hyperparameter-effects/         companion page that checks hyperparameter effects against the literature
```

## Editing the text

All prose is in `index.html`, between `<article>` and `</article>`. Section headings are `<h2 id="...">` elements, and the contents list on the left is built from the headings that have an `id` when the page loads.

Citations are numbered by hand. A citation in the text is `<sup><a href="#ref3">[3]</a></sup>`, and it points to `<li id="ref3">` in the reference list at the end of the article. If you add a reference in the middle, renumber the later ones in both places.

Figure captions are the `<figcaption>` elements next to each figure. The figures themselves are drawn by `figs.js` and `traj.js`. Change those files only to change how a figure looks.

## Figure data

`data/traj_data.js` is generated by `src/cl_blog_traj_data.py` in the code repository. Do not edit it by hand. To update it, rerun that script and copy its output here in one commit.

## Preview before pushing

```
python3 -m http.server 8000
```

Then open http://localhost:8000/ in a browser. Opening `index.html` as a file also works for the text, but some browsers block the figure scripts on `file://` pages.

## Working together

Pull before you start editing (`git pull`), and push small commits. For larger rewrites, open a pull request so the other author can review the change before it goes live.

The page has a `robots` noindex tag, so search engines leave it out. It is still public to anyone with the link.
